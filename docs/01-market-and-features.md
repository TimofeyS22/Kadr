# Kadr: рынок, позиционирование, фичи

Дата: 2026-09-28. Уровень источников: A — первичные, B — аналитика с методологией, C — пресса и обзоры (только как сигнал).

## BLUF

**Рекомендация:** делать мобильный web-редактор (PWA) с локальной обработкой: «CapCut-уровень монтажа в браузере, бесплатно, без водяных знаков, видео не покидает телефон». Первая версия — один отполированный цикл «импорт → монтаж → экспорт MP4». Бесплатное ядро. Платить потом можно только за облачный AI.
**Уверенность: средняя.** Спрос доказан: CapCut зарабатывает больше $1 млрд в год, а пользователи недовольны его пейволлом. Но бесплатные нативные конкуренты сильны (Adobe Premiere mobile, Meta Edits, VN). Ставка держится на нише, которую они не закрывают: работа по ссылке без установки, приватность и любое устройство.
**Вывод изменится, если:** на G2 активация (экспорт в первой сессии) окажется ниже 25% или web-экспорт не выйдет на ≥ 1× реального времени на средних телефонах.

## 2. Карта конкурентов

| | CapCut | Premiere mobile | Meta Edits | VN | Clipchamp/Kapwing/VEED | **Kadr** |
|---|---|---|---|---|---|---|
| Платформа | Нативное + web | Нативное | Нативное | Нативное | Web, десктоп | **Web, мобильный first** |
| Установка | Нужна | Нужна (Android: 5 ГБ RAM) | Нужна | Нужна | Нет | **Нет, PWA** |
| Цена ядра | Урезано, Pro $19,99 | Бесплатно | Бесплатно | Почти бесплатно | Freemium | **Бесплатно** |
| Где обрабатывается видео | Облако + устройство | Устройство + облако | Устройство | Устройство | Облако | **Только устройство** |
| Водяной знак | В части функций | Нет | Нет | Нет | В free у части | **Нет** |

**Позиционирование (гипотеза):** «Открыл ссылку — смонтировал — сохранил. Видео не покидает телефон». Целевые пользователи:
1. Креаторы коротких видео, которым не нравится пейволл CapCut.
2. Устройства, где нельзя ставить приложения: школьные и рабочие Chromebook, корпоративные телефоны.
3. Люди, которые не хотят отдавать контент в облако.
4. Разовые задачи вроде «обрезать и подписать видео», ради которых не хочется ставить приложение.

## 3. Red team / pre-mortem

| Сценарий провала | Вероятность | Контрмера |
|---|---|---|
| Бесплатные Premiere и Edits делают «ещё один бесплатный редактор» ненужным | Высокая | Не конкурируем в App Store. Каналы — поиск (SEO по задачам вроде «обрезать видео онлайн на телефоне»), шаринг ссылкой, устройства без установки |
| Web на телефоне медленнее нативного: лаги, крэши по памяти в Safari | Средняя | Перф-бюджеты, превью в пониженном разрешении, агрессивное освобождение декодеров, тесты на реальных устройствах на G1 |
| iOS вытесняет данные сайта из хранилища, проект пропадает | Средняя | `navigator.storage.persist()`, предупреждение в UI, экспорт и импорт проекта файлом (v0.2) |
| Монетизация невозможна: у владельца нет платёжного счёта вне РФ | Высокая | v0.x бесплатна. Платёжную схему решаем до запуска облачных AI-фич. Это блокер только для выручки, но не для продукта |
| Отсутствие аккаунтов = нет retention-канала | Средняя | Устанавливаемая PWA, список проектов на главном экране, позже — опциональный облачный бэкап |

## 5. Метрики и гейты

| Метрика | Определение | Порог |
|---|---|---|
| Активация | Доля новых пользователей с успешным экспортом в 1-й сессии | ≥ 40% (kill-сигнал < 25%) |
| Успешность экспорта | Успешные экспорты / начатые | ≥ 98% |
| Crash-free sessions | | ≥ 99,5% |
| Time-to-first-export | Медиана | ≤ 5 мин |
| D1 / D7 / D30 (установившие PWA) | | Нет бенчмарка для web-редакторов (не найдено), фиксируем базу на бете |

- **G1 — Alpha (конец недели 2):** базовый цикл работает в iOS Safari 26 и Android Chrome на реальных устройствах. Превью 1080p ≥ 30 FPS, экспорт ≥ 1× реального времени. 5 тестеров проходят цикл без подсказок.
- **G2 — Public beta (+2–4 недели):** 50–200 пользователей, активация ≥ 40%, успешность экспорта ≥ 98%.
- **G3 — Scale:** органический рост из поиска и шаринга, решение о нативных обёртках и облачном AI.
