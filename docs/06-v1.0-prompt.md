# Kadr v1.0 — системный промпт: монтаж «как в CapCut, только лучше»

> Читается перед работой над v1.0 вместе с `CLAUDE.md`. Инварианты `docs/03` §2 и бюджеты `docs/04` §3 в силе.
> Написан 2026-10-09 по отзыву владельца после реального использования на телефоне.
> Цель — пользователь CapCut не находит, чем мы хуже в базовом монтаже, и находит, чем лучше: приватность, без водяных знаков, без лимитов.

## 1. Отзыв владельца (исходные данные)

| # | Цитата (смысл) | Диагноз по коду |
|---|---|---|
| 1 | «Обрезка слева происходит справа» | Главная дорожка — «магнитная»: при подрезке начала клип тут же сдвигается влево (`packMain`), и под пальцем двигается правый край, а левый стоит |
| 2 | «По умолчанию голос оставлять без изменений» | При смене скорости голос меняет высоту тона («бурундук»); сохранение тона — выключенный по умолчанию тумблер |
| 3 | «В суфлёре изменения не отображаются» | Пока открыт редактор сценария, суфлёр скрыт: размер и скорость меняются вслепую |
| 4 | «В скорость добавить 1.25» | Пресеты 0.25 / 0.5 / 1 / 1.5 / 2 / 4 — нет самого ходового ускорения для разговорных роликов |
| 5 | «Субтитры кривые, надо на всё видео + стили (по слову или нет)» | На iPhone по умолчанию самая слабая модель (tiny); распознаётся только то, что VAD признал речью (под музыкой куски теряются); выбор вида (по слову / фраза) спрятан в редактор после генерации |
| 6 | «При перетаскивании куска экран не двигается» | Нет автопрокрутки таймлайна у краёв экрана при переносе и подрезке |

## 4. Спецификации и критерии приёмки

### M1. Подрезка начала клипа «край за пальцем»

- Во время перетаскивания левой ручки клипа главной дорожки клип и всё после него визуально стоят на месте, левый край идёт за пальцем (смещение отображения, модель уже обрезана).
- Превью показывает кадр на новом начале (для правой ручки — на новом конце), а не кадр под плейхедом. После отпускания превью возвращается к плейхеду.
- После отпускания пробел закрывается (магнитная дорожка), как раньше.
- **AC (e2e):** тянем левую ручку вправо на 60 px → левый край клипа сдвинулся на ≈ 60 px, правый край на месте (±3 px) до отпускания; после отпускания длительность клипа меньше на ≈ 1 с.

### M2. Автопрокрутка таймлайна при переносе и подрезке

- Палец ближе 56 px к левому/правому краю таймлайна → таймлайн прокручивается в ту сторону; скорость растёт к краю (до ~ 900 px/с).
- Смещение клипа учитывает прокрутку: клип остаётся под пальцем.
- **AC (e2e):** длинное видео, клип наложения тянем к правому краю и держим → `scrollLeft` растёт, клип после отпускания начинается позже, чем позволял бы сдвиг пальца без прокрутки.

### M3. Скорость: 1.25× и естественный голос по умолчанию

- Пресеты: 0.25, 0.5, 1, 1.25, 1.5, 2, 4.
- `keepPitch` по умолчанию включён (`keepPitch !== false`); тумблер — «Естественный голос».
- Звук с сохранённым тоном готовится автоматически после смены скорости (в листе) и **перед экспортом** для всех клипов, у которых он устарел. Пока не готов, превью играет как раньше.
- **AC:** юнит — `expectedAudioKey` для клипа 1.25× без явного `keepPitch` содержит `p1.25`; e2e — 1.25× → экспорт → длительность звука ≈ длительность видео, тон (доминирующая частота тестового сигнала) сохранён ±3 %.

### M4. Суфлёр: что видишь — то и будет

- Редактор сценария внизу, суфлёр вверху остаётся видимым и сразу отражает размер текста.
- Кнопка «Проверить скорость» прокручивает текст с выбранной скоростью до начала записи.
- **AC (e2e):** открыть редактор → суфлёр виден; размер 40 → `font-size` суфлёра 40 px; «Проверить скорость» → `scrollTop` растёт.

### M5. Субтитры на всё видео, точнее, с выбором вида

- **Покрытие:** распознаём всю речь, а не только уверенные куски VAD. Гипотеза «мягкие пороги VAD» проверена замером и **отвергнута**: под громкой музыкой WER вырос (16,9% → 28,6%). Остались прежние пороги и фильтр артефактов Whisper.
- **Точность:** модель по устройству и выбору: «Быстро» (base), «Точно» (small). Ускорение WebGPU, где есть, иначе WASM. Замер решает, что ставить по умолчанию на iPhone.
- **Вид до генерации:** «Фраза», «По слову» (одно слово на экране), «Подсветка слова» (фраза + активное слово), плюс стиль (цвет/шрифт).
- **Стабильность:** строка фразы не «прыгает» и не переносится по-разному от кадра к кадру.
- **Eval (обязателен до выбора модели):** эталонные русская и английская речь (TTS, со сценарием) чистые и под музыкой; метрики — WER и coverage на каждой модели, время на десктопе. Таблица результатов — в `docs/02` (changelog v1.0).
- **AC:** e2e — субтитры созданы на всё видео (последнее слово ближе 1.5 с к концу речи); вид «По слову» показывает одно слово; eval: coverage ≥ 0.9 под музыкой, WER не хуже прошлой версии.

### M6. Документы и честность

- Changelog v1.0 в `docs/02` с таблицей eval; что не проверено на телефоне — так и пишем.

## 5. Definition of Done

- `npm run check` и полный `npm run e2e` зелёные на WebKit и Chromium; новые сценарии на M1–M5.
- Проверка в браузере (мобильный вьюпорт) со скриншотом.
- Публикация на GitHub Pages, проверка, что живая сборка содержит изменения.

## 6. Red team (pre-mortem)

| Риск | Что делаем |
|---|---|
| Модель small (~250 МБ) слишком тяжёлая для телефона: долгая загрузка, вылет по памяти | По умолчанию на iPhone — то, что покажет eval по соотношению качество/вес; small — явный выбор с размером в подписи |
| WebGPU на iOS ведёт себя иначе, чем в Chromium | Fallback на WASM при любой ошибке инициализации; режим в телеметрии |
| Обработка тона на длинных клипах занимает время | Прогресс и отмена; перед экспортом — общий прогресс; кэш по ключу скорости |
| Автопрокрутка «уносит» таймлайн при случайном касании края | Только во время активного переноса/подрезки, порог 56 px, плавный разгон |
