## 2. Инварианты (нарушение = P0)

1. **Приватность.** Медиа и текст речи не покидают устройство. Из сети скачиваются только модели и CC0-музыка.
2. **Всё отменяется.** Каждый шаг «Рилса» — отдельная запись в истории. «Отменить всё» возвращает проект к состоянию до запуска. Пользователь видит, что именно сделано.
3. **Ничего не теряется.** Автомат не вырезает слова речи. Вырезаются только паузы и слова-паразиты, края вырезов — по тихим точкам (`wordCutRange`).
4. **Честное время.** Прогресс с фазами. Отмена в любой фазе оставляет проект целым.
5. **WYSIWYG.** Всё, что делает «Рилс», — обычные клипы, ключевые кадры и субтитры, видимые и редактируемые на таймлайне.
6. **Статичные страницы задач без трекинга и сторонних скриптов.** CSP сайта не ослабляется.

## 3. Спецификации и критерии приёмки

### A. «Рилс в 1 тап»

**Конвейер.** Чистая логика — в `src/core/autoreel.ts` (юнит-тесты), оркестрация — в `src/ui/autoreel.ts`.

1. **Распознавание:** вся речь таймлайна, модель base, язык по интерфейсу (как в v1.0).
2. **Субтитры:** клип субтитров из слов без паразитов. Вид «Подсветка слова», стиль по выбору (по умолчанию «Bold»).
3. **Паузы:** по энергии (`speechRanges`, настройки `DEFAULT_PAUSES`), в пересчёте на время таймлайна.
4. **Слова-паразиты и повторы:** `fillerIndices` → вырезы по тихим точкам.
5. **Один общий вырез** (`cutTimelineRanges`): субтитры сдвигаются вместе с видео.
6. **«Джамп-зум»:** каждый второй кусок после выреза приближен на 12% (держится весь кусок). Так прячут склейки профессионалы. Горизонтальное видео в вертикальном проекте заполняет кадр (`cover`) по центру.
7. **Заголовок-хук:** первая фраза (≤ 7 слов) крупным текстом сверху на первые 2,5 с.
8. **Музыка:** CC0-трек выбранного настроения (по умолчанию «Спокойная»), по длине ролика, с затуханием и **приглушением под голос** (`duck` 0,8).

**UI:**
- Лист «Рилс в 1 тап»: тумблеры шагов (все включены), стиль субтитров, настроение музыки (или «без музыки»), язык.
- Большая кнопка, прогресс по фазам, отмена.
- Итог: список сделанного с числами (например, «−14 пауз, −6 „эээ“, 38 с → 29 с») и «Отменить всё».

**Входы:**
- кнопка в панели инструментов (первая);
- карточка на главном экране «Рилс в 1 тап»: выбор видео → вертикальный проект → конвейер стартует сам.

**Метрики (телеметрия):** `reel_started`, `reel_done` {секунды, вырезано с, паузы, паразиты, шаги}, `reel_cancelled`, `reel_undo_all`.

**AC:**
- **Юнит:**
  - вырезы паразитов и пауз сливаются и не задевают слова речи;
  - джамп-зум чередует масштаб;
  - хук берёт первую фразу ≤ 7 слов;
  - отмена каждого шага (история).
- **e2e на двух движках.** Запись речи с паузами и «эээ» → «Рилс в 1 тап». Проверить:
  - ролик короче;
  - есть субтитры, хук и музыка с приглушением;
  - масштаб чередуется;
  - «Отменить всё» возвращает исходную длительность;
  - экспорт проходит.
- **Eval (`EVAL=1`).** На эталонной записи с паузами и паразитами:
  - доля сохранённых слов речи ≥ 95% (по субтитрам после конвейера);
  - удалено ≥ 70% длительности пауз;
  - время конвейера на десктопе.

### B. «Поделиться → Kadr» (Android, Web Share Target)

- **Манифест:** `share_target`, POST `multipart/form-data`, поле `media`, типы `video/*`, `image/*`, `audio/*`.
- **Service worker** (добавка к сгенерированному Workbox через `importScripts`):
  - перехватывает POST на `share-target`;
  - кладёт файлы в Cache Storage `kadr-share`;
  - отвечает редиректом 303 на `./#/share`.
- **Приложение** по `#/share`:
  - забирает файлы и очищает кэш;
  - создаёт вертикальный проект, импортирует файлы (видео и фото на главную дорожку, звук — на звуковую) и открывает редактор;
  - ошибки — понятным тостом.
- **Установка PWA.** Kadr появляется в меню «Поделиться» только у установленного PWA. Поэтому на главном экране кнопка «Установить Kadr» (событие `beforeinstallprompt`, только где оно есть) с подсказкой «чтобы делиться видео из галереи».
- **iOS** (нет Web Share Target): ничего не показываем, не обещаем.
- **Метрики:** `share_target_received` {files, kinds}, `pwa_install_prompted` / `pwa_installed`.
- **AC (e2e, Chromium, прод-сборка с SW):** POST multipart с видео на `share-target` → по `#/share` создан проект с клипом на таймлайне; кэш `kadr-share` пуст.

### C. Страницы задач и глубокие ссылки

**Контент:** `seo/tasks.ts`, 10 задач × RU/EN = 20 страниц:
- рилс из записи речи;
- субтитры;
- удаление пауз;
- ускорение;
- музыка без авторских прав;
- удаление фона;
- суфлёр;
- шумоподавление;
- обрезка;
- видео в GIF.

**Каждая страница уникальна:**
- `<title>` ≤ 60 символов, description ≤ 160;
- H1, вступление, 3–5 шагов, «почему Kadr» (бесплатно, без водяного знака, видео не покидает телефон), FAQ из 3–4 вопросов;
- ссылки на соседние задачи, переключатель языка (`hreflang`);
- JSON-LD `SoftwareApplication` + `HowTo` + `FAQPage`, canonical.

**Сборка:**
- плагин Vite генерирует статичный HTML без JS, CSS инлайн, вес ≤ 20 КБ;
- плюс `sitemap.xml` и `robots.txt` в `dist/`.

**Глубокая ссылка `#/start/<task>`:**
- главный экран показывает баннер задачи и кнопку «Выбрать видео» (выбор файла требует жеста);
- дальше — проект и нужный инструмент сразу открыт. Для `reel` стартует конвейер.

**Главная страница:** нормальный `<title>`, description, Open Graph.

**Метрики:** `deeplink_task` {task}, `deeplink_started` {task}.

**AC:**
- юнит: каждая страница проходит лимиты, уникальные title и description, валидный JSON-LD, ссылки только на существующие страницы;
- e2e: страница задачи открывается, кнопка ведёт в Kadr, баннер есть, после выбора видео открыт нужный инструмент.

## 4. Definition of Done (для каждой ставки)

- `npm run check` и полный `npm run e2e` зелёные на WebKit и Chromium. Новые сценарии на A, B, C.
- Проверка в браузере в мобильном вьюпорте, скриншот.
- Changelog v1.1 в `docs/02`: что сделано, замеры, что не проверено на телефоне.
- Публикация, проверка живой сборки (страницы задач отдаются, манифест содержит `share_target`).

## 5. Red team (pre-mortem разработки)

| Риск | Что делаем |
|---|---|
| Автомат вырезает слоги или съедает слова | Вырезы по тихим точкам; eval «сохранено ≥ 95% слов»; каждое действие отменяется |
| Распознавание долгое на iPhone (base ≈ 1× длины видео) | Честный прогресс; паузы и зум не ждут распознавания, если субтитры и паразиты выключены |
| Нет речи (музыкальное видео) | «Речь не найдена»: делаем только зум и музыку, говорим об этом |
| Share target не срабатывает без установки PWA | Кнопка установки; метрика доли сессий из «Поделиться» |
| SW-добавка ломает офлайн-кэш Workbox | Добавка обрабатывает только POST на свой путь; офлайн-тест остаётся в наборе |
| Страницы на `github.io/Kadr/` слабо ранжируются; `robots.txt` не в корне хоста | Sitemap отправляется в Search Console (это делает владелец); позже свой домен. Честно пишем в отчёте |
| Тонкий контент → фильтры поисковиков | 20 уникальных страниц с реальными шагами и FAQ, без генерации «на ключи» |
