# Kadr: архитектура и план реализации

Дата: 2026-09-28.

## 1. Обзор

Локальное приложение без бэкенда: статическая PWA, вся обработка на устройстве.

```
UI (React)  ──commit()──►  Store (Zustand: project + history + UI state)
   │                              │  autosave (debounce)
   │                              ▼
   │                        Storage (IndexedDB: проекты JSON, медиа Blob, пики волн)
   ▼
Player / Exporter ── buildFrame(project, t) ──► FrameDesc (чистые данные)
   │                                              │
   ├─ MediaPool: Input на ассет (Mediabunny) ─────┤ кадры клипов (CanvasSink)
   ├─ TextRasterizer (2D canvas → текстура) ──────┤
   ▼                                              ▼
AudioEngine (Web Audio)               Compositor (WebGL2: трансформы, цвет, хромакей, переходы, фон)
   │                                              │
   └─ экспорт: OfflineAudioContext по окнам ──► Mediabunny Output (MP4: H.264 + AAC)
```

**Ключевое свойство — WYSIWYG.** Превью и экспорт вызывают одни и те же `buildFrame` и `Compositor`. Различается только источник времени (аудиоклок или счётчик кадров) и режим декодирования (допускаем пропуск кадров или ждём точный кадр).

## 3. Модель данных (кратко)

- `Project { settings { width, height, fps, background }, tracks[] }`. Дорожки идут снизу вверх (порядок композитинга). Дорожка `main` магнитная, её клипы упакованы встык с учётом перекрытий переходов.
- `Clip`: `start` и `duration` на таймлайне (с). У медиаклипов есть `in` (секунда источника) и `speed`, отсюда `srcTime = in + (t - start) * speed`.
- Анимируемые свойства: `{ v, k?: [{ t, v, e }] }`. Время ключей относительно клипа; интерполяция с easing.
- Переход хранится у клипа как `transitionIn { type, duration }` и перекрывает его с предыдущим клипом main-дорожки.
- Медиа хранится отдельно от проекта (`Asset` + Blob), проект ссылается на `assetId`. Снимок истории — лёгкий JSON.

## 4. ADR (решения)

| # | Решение | Альтернативы | Почему | Пересмотреть, если |
|---|---|---|---|---|
| 1 | PWA сначала, Capacitor потом | Нативный Swift/Kotlin, Flutter | Один код, дистрибуция ссылкой, агент собирает и проверяет из CLI | Web-перф не проходит G1 |
| 2 | WebCodecs через Mediabunny | ffmpeg.wasm | Аппаратное ускорение (в 10–50 раз быстрее wasm), нет 30 МБ wasm, работает на iOS 26 | Нужны экзотические кодеки: тогда ffmpeg.wasm как ленивый fallback |
| 3 | WebGL2-композитор | Canvas 2D, WebGPU | WebGL2 есть везде (iOS 15+). Шейдеры нужны для цвета, хромакея и переходов. `ctx.filter` в Canvas 2D поддерживается нестабильно. WebGPU есть не везде | WebGPU станет повсеместным (ускорение AI-эффектов) |
| 4 | IndexedDB для Blob медиа | OPFS | Работает во всех браузерах одинаково, Blob читается кусками | Упрёмся в экспорт больших файлов: тогда OPFS StreamTarget |
| 5 | Иммутабельный документ + снимки истории | Command pattern, CRDT | Проще и надёжнее. Документ маленький (килобайты), undo бесплатен для всех операций | Появится совместное редактирование: тогда CRDT (Yjs) |
| 6 | Экспорт в главном потоке (v0.1) | Worker + OffscreenCanvas | Быстрее реализовать, шрифты и текст проще. Цикл уступает event loop | UI заметно фризит при экспорте: переносим в worker (v0.2) |
| 7 | Без бэкенда | Облачный рендер | Приватность, стоимость $0, нет ПД → меньше юридических рисков | Облачный AI (v0.3+) |

## 5. Безопасность и приватность

- Никаких сетевых запросов с контентом. Шрифты вшиты в бандл (OFL), внешние CDN не используются. CSP: `default-src 'self'`.
- Вредоносные файлы разбирает парсер Mediabunny в песочнице браузера, декодирует браузер. На случай битых файлов стоят таймауты и try/catch на импорте.
- Лимиты: размер одного файла ≤ 4 ГБ (предупреждение с 1 ГБ), длительность проекта ≤ 30 мин (v0.1).

### Безопасность новых частей
- CSP расширяется точечно: `connect-src` для `huggingface.co`, `*.hf.co`, `cdn.jsdelivr.net` (модели и WASM ORT), `script-src 'wasm-unsafe-eval'` для WASM. Звук и видео пользователя никуда не отправляются, скачиваются только файлы модели.
- Перед первой загрузкой модели показываем размер и просим подтверждение.
- Импорт `.kadr` валидирует JSON (версия схемы, типы) и не исполняет ничего из архива.

**Проверки:** `npm run check` — 32/32 тестов. Прод-сборка: стартовый JS ≈ 85 KB gzip. AI-чанки ленивые и кэшируются при первом использовании (RNNoise 4,8 МБ, воркер ASR 0,5 МБ + WASM ORT 26,8 МБ, модели 41/77 МБ — с Hugging Face один раз).

**Решения по ходу:**
- Нейтральная графитовая палитра и плёночный янтарь вместо почти чёрного фона с красным акцентом (промпт плагина frontend-design).
- На телефоне превью ужимается над открытой шторкой.
- На iOS по умолчанию модель tiny.

**Известные ограничения v0.2:**
1. WASM ORT 26,8 МБ требует хостинга с файлами больше 25 МБ: GitHub Pages и Netlify подходят, Cloudflare Pages — нет.
2. ASR однопоточный: без cross-origin isolation многопоточность WASM недоступна.
3. Отменённое шумоподавление через undo оставляет файл в хранилище до удаления проекта.
4. Whisper «галлюцинирует» текст на музыке без речи. Нужен детектор речи (VAD) перед распознаванием (v0.3).
5. Скорость ≠ 1× по-прежнему меняет тон (SoundTouch — v0.3).

**Следующий шаг:** G1 на реальных устройствах (`npm run dev -- --host`): субтитры RU/EN на iPhone (tiny) и Android (base), войсовер, экспорт → «Фото». Затем v0.3 (Should-список отчёта).

## 19. Статус на 2026-10-01 (v0.8: музыка, ориентир, стили текста, свои шрифты, удаление фона — по `docs/05`)

**M1. Музыкальная библиотека.**
- 48 треков, по 6 на каждое из 8 настроений (Lo-fi, Энергичная, Фонк, Кино, Спокойная, Весёлая, Игровая, Электроника). Авторы — HoliznaCC0, Komiku, Loyalty Freak Music (Free Music Archive).
- **Лицензия:** у каждого трека CC0 1.0 проверена на его странице; ссылка-доказательство и дата проверки лежат в `public/music/music.json`.
- **Сборка:** `python3 scripts/build-music.py && npx tsx scripts/music-beats.ts` — двухпроходная нормализация до −14 LUFS, AAC 128 Кбит/с (144 МБ); бит считает код самого приложения (31 трек из 48 с ровным битом).
- **В приложении:**
  - лист «Музыка»: настроения и прослушивание;
  - «Добавить» подгоняет трек под длину видео с затуханием 2 с;
  - сетка битов сразу в ассете, поэтому «Нарезать в бит» работает без анализа;
  - «Скопировать лицензию» — для спора с Content ID.
- **Кэш:** треки кэшируются PWA при использовании (CacheFirst; запросы диапазонов для прослушивания идут в сеть), список — StaleWhileRevalidate.

**M2. Трек-ориентир.** `Sound.guide`: звучит при монтаже, исключается из любого экспорта (`withoutGuides`); на таймлайне есть метка «Ориентир».

**M3. Стили и шрифты.**
- 24 новых стиля (всего ≈ 40); кнопка стиля рисует сам стиль: шрифт, цвет, обводку, фон, свечение.
- Свои шрифты: TTF/OTF/WOFF/WOFF2 до 15 МБ с проверкой `FontFace.load()`; blob хранится в IndexedDB, описание — в `Project.fonts`; одно начертание на 100–900 (без фальшивого жирного); шрифт попадает в бэкап и восстановление, удаляется вместе с проектом.

**M4. Удаление фона.**
- **Причина:** маска 256 px растягивалась, и на краю оставались ступеньки и светлая кайма фона (видно на светлом фоне вокруг тёмной одежды).
- **Исправление:**
  - на краю маски прозрачность определяется цветом (локальный мэттинг: ближе к уверенным пикселям человека или фона в окрестности 5×5);
  - внутренние пиксели не пересчитываются;
  - на видео маска сглаживается во времени между соседними кадрами (только последовательными, поэтому перемотка не тянет старую маску).
- **Результат:** кайма 578 → 262 пикселя (−55%) по метрике в e2e; скорость на стенде S3 — 61,7 кадра/с, кадр p95 20 мс.
