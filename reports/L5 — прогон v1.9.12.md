# L5 — прогон v1.9.12

> План одного подхода к iPhone 15 после выпуска v1.9.12: очередь `reports/L5 — очередь.md` скриптами и руками, по цене для человека (`docs/16` §6). Формат строк — `docs/21` §9. Результаты — в `reports/L5 — журнал.md`.
> Составлен 2026-11-17. Пороги строк очереди не менялись. Пороги участка L (в очереди их не было) записаны здесь, до прогона (§5).

## 0. Коротко

- **Скрипты:** `scripts/l5-sweep-{a,b,c,d,e,l}.mjs`. U — `scripts/l5-sweep-u.mjs` на ветке `l5-u` (сессия Chetko). S — команды раздела S очереди (сессия субтитров).
- **Покрытие:** скриптом проверяются 49 строк очереди целиком или в части, которую видит страница. Ещё 6 строк скрипт собирает, а сравнивает человек (LOOK). Только вручную — 67 строк: палец, окна «Фото» и «Файлы», частная вкладка, сеть, другой телефон, календарь.
- **Время (оценка):** скрипты ≈ 5 ч 30 мин, телефон в это время не нужен человеку. Ручные шаги ≈ 3 ч 30 мин. Всего ≈ 9 ч одного дня. Самый долгий блок — 60 прогонов камеры S-1-13 (≈ 75 мин), его лучше ставить на перерыв.
- **Что печатает скрипт:** по строке `PASS`, `FAIL`, `ERROR` (сценарий сломался до замера, это не вердикт о продукте) или `LOOK` (собрано, сравнивает человек). Рядом — измеренное значение и порог. В конце — ручные шаги участка с порогами.

## 1. Перед прогоном (10 мин, владелец)

1. iPhone 15 по кабелю, разблокирован, «Автоблокировка → Никогда». В «Safari → Дополнения» включены Web Inspector и Remote Automation (настройки не менять, только проверить).
2. На Mac: `pgrep -fl safaridriver` — пусто. Одна сессия WebDriver на телефон. Сессию Chetko на это время не запускать.
3. Скрипты запускаются из `~/Developer/kadr` (там `fixtures/` с медиа; иначе `npm run fixtures`). В рабочем дереве без медиа нужны ссылки на `~/Developer/kadr/fixtures/*`.
4. Папка доказательств — внутри рабочего дерева: `.e2e-out/l5-v1.9.12/<участок>`. Не `/tmp`: он чистится при перезагрузке.
5. Первый дубль просит камеру, первая озвучка — микрофон: нажать «Разрешить» на телефоне.

Команда участка:

```bash
L5_UDID=00008120-0016288E26000032 L5_OUT=.e2e-out/l5-v1.9.12/a node scripts/l5-sweep-a.mjs https://timofeys22.github.io/Kadr/
```

Переменные: `L5_ONLY=V-248,SW-A-19` — только эти строки; `L5_PRICE=1,2` — только строки этой цены; `L5_KEEP=1` — проекты остаются на телефоне; `L5_REPS` (3) — повторы строк «3 из 3»; `L5_EXPECT` (v1.9.12) — версия в подвале; `L5_CAMERA_RUNS` (60); `L5_V258_WAIT` (300 с).
После каждого участка: `sweep-<участок>.md` из папки — в журнал, `sweep-<участок>.json` и снимки остаются в папке. Между участками телефон 20–60 с не даёт новую сессию: скрипт сам повторяет каждые 20 с до 4 минут.

Как скрипт заменяет человека (`L5-авто`, `docs/16` §4; пишется в журнал):

- Касания — `click()` и события пальца в странице. Задержки настоящего пальца в замере нет.
- Медиа кладутся в страницу вместо окон «Фото» и «Файлы». Готовый файл забирается на Mac кусками по 3 МБ вместо листа «Поделиться».
- «Закрыть вкладку и открыть» заменены новой страницей сайта (D-6) и командой «Обновить» WebDriver (SW-A-19). Убийство вкладки системой остаётся ручным.
- Q-11: крайние значения «Настройки», фильтр Cyber и эффекты записаны в сохранённый проект, а не протянуты в листах. LUT не ставится: сравнивается рендер, а не путь пальца.
- S-1-12 считается на тех же 60 прогонах, что S-1-13: 300 дублей вместо 100, но без фонового экспорта.
- V-170: пять экспортов, затем субтитры и ещё экспорт подряд. Интерфейс не даёт двух задач одновременно.
- C-C3: время главной — верхняя граница: часы страницы при первом взгляде после события `load`. Время примера — точное, в странице. Холодный только первый запуск сессии (у каждой сессии пустые данные сайта).
- Декодеры (V-171) считаются только в странице, без воркеров, как в e2e.
- Память вкладки Safari странице не отдаёт. Все пороги памяти — Web Inspector, вручную.

## 6. Проверка без телефона

- `node --check` всех `scripts/l5-*.mjs` — без ошибок.
- `scripts/l5-verdict.test.ts` — 21 тест чистой логики порогов. Проверено: строка FAIL важнее LOOK; ничего не измерено — ERROR, а не PASS; S-1-13 падает от одного тоста, пустой полосы или третьей новой аренды; прогон, потерянный по кабелю, не засчитывается; пары «вспышка + писк»; пакеты AAC; стыки V-153; WYSIWYG; WER; выбор строк по `L5_ONLY` и `L5_PRICE`.
- Анализ на Mac прогнан на настоящих фикстурах: `avsync_long.mp4` — 8 пар по 0 мс; пакеты AAC целые; `tone1k.mp4` — стыки −0,26…+0,15 дБ, скачок ×0,97–0,99. Все команды ffmpeg, которые делают тестовые файлы, проверены.
- `npm run check` и `npm run lint` — зелёные.
- Репетиция в Safari на Mac (`L5_MAC=1`) не состоялась: Safari на этом Mac не дал сессию автоматизации (тайм-аут запуска). Настройки не трогались. Первая проверка скриптов — прогон на телефоне (§7).
