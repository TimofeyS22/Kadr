# Chetko — было и стало

> Карта переноса экранов на дизайн-систему (`docs/17` §6, этап Ч4, условие Д7). Левая колонка — опись версии 1.7.1 (`reports/Chetko — аудит интерфейса.md` §4). Правило: каждая функция достижима за то же или меньшее число касаний, ничего не переезжает молча.
> Каждый релиз Ч4 добавляет сюда свой раздел.

## Релиз 1 — перекраска без смены раскладки (2026-11-10)

**Что не изменилось:** раскладка всех экранов, места и порядок всех инструментов, число касаний до любой функции, тексты.

**Что изменилось на вид:**

| Было (1.7.1) | Стало | Почему |
|---|---|---|
| Главная кнопка («Новый проект», «Экспорт») янтарная | Белая | В системе цвет оставлен для метки значения; главное действие — белое (`DESIGN.md` §2) |
| Выбранный чип, вариант — янтарная заливка | Белая рамка, белый жирный текст на тёмном | Сплошная белая заливка оставлена только действиям, иначе выбранный чип похож на главную кнопку (замечание рецензента) |
| Выбранная плитка фильтра — янтарная подпись | Белая рамка вокруг всей плитки | Подпись одна сливалась со светлой миниатюрой |
| Включённый инструмент (маска, эффект) окрашен янтарём | Белая метка рядом со значком | Цвет не единственный признак; у инструмента нет состояния «нажато» |
| Ползунок значения янтарный, цифра серая | Ползунок и цифра значения — жёлтый сигнал | Жёлтый в системе — цвет текущего значения и его цифры |
| Неактивный «Экспорт» — приглушённый янтарь | Контур с бледной надписью | Сплошная серая «пилюля» выглядела как обычная кнопка |
| Кнопка «Назад» в ленте прозрачная, при прокрутке на ней просвечивает соседний инструмент (UI-1) | Непрозрачная | Дефект: касание по видимому инструменту попадало в «Назад» |
| Карточка «Рилс в 1 тап» с янтарной заливкой | Нейтральная карточка с рамкой и шевроном «›» | Ушёл янтарь; шеврон говорит, что на неё нажимают; подпись проходит 4,5:1 |
| Фон графитовый, панели светлее | Почти чёрный с лёгким холодным оттенком, панели на шаг светлее | Нейтральная среда вокруг кадра (`DESIGN.md` §2.1) |
| Дорожки текста, звука, субтитров яркие | Те же оттенки, вдвое тише | Решение владельца 2026-11-10: цвет — вторая подсказка |
| Шрифт интерфейса Inter (веса 400, 700, 900; CSS просил 600, которого не было) | Geologica, любой вес | Шрифт системы. Интерфейс тянет 48 КБ шрифта вместо примерно 95 КБ; Inter остаётся в офлайн-кэше как шрифт текста на видео, поэтому кэш вырос на 48 КБ. Работает офлайн с первого визита |
| Кнопка языка: неактивная надпись 4,38:1 | 5,3:1 | Найдено проходом контраста после перекраски |

**Чего ещё нет в этом релизе:** скругления, кегли и отступы старых экранов прежние; листы с ползунками ещё не заменены «Шкалой»; знак «Kadr» прежний до этапа Ч5.

**Проверено:** проход контраста по 35 экранам — 0 текстов ниже AA; дымовой тест, галерея, плитки фильтров, доступность и тесты экранов на прод-сборке на WebKit и Chromium — после правок рецензента 26 ✓, 2 пропуска по условию (до правок с галереей — 49 ✓). Обход 42 экранов на английском и на 320 px: боковой прокрутки нет, ошибок нет. На iPhone **не проверено**.

**Замечено и не исправлено:** на 320 px название проекта в шапке редактора обрезается до трёх букв без многоточия (известно с Ч0; Geologica шире Inter, и букв стало меньше). Уходит в релиз каркаса редактора.

**Независимый рецензент:** «выпускать после правок» — пять правок внесены (строки выше). Его прогноз: жалобы «всё переехало» не будет, «стало блёклее» вероятна.
