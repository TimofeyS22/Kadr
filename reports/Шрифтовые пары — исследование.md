# Шрифтовые пары — исследование (этап П0)

> По `docs/18-font-pairs-prompt.md`. Метки: **ФАКТ**, **ОЦЕНКА**, **ГИПОТЕЗА**. Дата: 2026-11-11.

**Итог.** Шрифты для русскоязычных пользователей CapCut — это прежде всего надёжность и деньги, а не число шрифтов. Половина жалоб: шрифты «не грузятся» и «стали платными». Ещё часть — шрифты пропадают из проектов. Красота шрифтов при этом удерживает людей даже в нелюбимом приложении.

Весь набор знаков `docs/18` Ш1 своими глифами рисуют 270 из 297 кириллических семейств Fontsource. Рукописных среди них 14. Значит, «эстетика по-русски» собирается из небольшого и известного набора, и выбирать его должен дизайнер по образцам, а не автоматический фильтр.

**Не сделано в П0:**
- ручная проверка разметки двумя разметчиками;
- счёт касаний в CapCut (нужна запись владельца);
- замер, сколько файлов шрифта грузит русский текст (§5).

## 2. Кириллица в открытых шрифтах

**ФАКТ.** API Fontsource, 2026-11-11, скрипт на `fontkit` 2.0.4 (MIT): он читает таблицу `cmap` из файлов woff2 подмножеств latin, cyrillic и cyrillic-ext.

- Всего 2103 семейства, с кириллицей — 297, все из Google Fonts. Лицензии: OFL-1.1 — 289, UFL-1.0 — 5, Apache-2.0 — 3.
- Набор Ш1 по `docs/18`: 66 русских букв, цифры, `« » „ “ ’ — – … № ! ? , . : ; ( ) " ' % ° × +` и латиница A–Z, a–z. Его своими глифами рисуют **270 из 297**.
- Контроль: в латинском Parisienne не хватает 67 знаков, проверка краснеет.
- Чаще всего не хватает «№» — 23 семейства, среди них Jost (он у нас уже есть), Alice и Viaoda Libre. Кавычек и тире не хватает у трёх.
- В Prata нет «…» и «№». В Kosugi нет «« » — –». В Pixelify Sans нет «О» и «П». В Neucha (он у нас есть) нет «×».
- Полные по категориям: гротески 123, антиквы 63, декоративные 52, моноширинные 18, **рукописные 14**.
- Знак `₽` лежит только в подмножестве latin-ext. Цена этого файла: Great Vibes — 64 KB, Montserrat — 31 KB, Cormorant — 19 KB. Поэтому по `docs/18` `₽` требуется только у шрифта опоры в парах для цен.

«№» остаётся обязательным, это решение после критики. Без него знак рисуется запасным шрифтом, а выбор без него всё равно широкий. Jost, Alice, Prata и Viaoda Libre в пары не идут.

## 5. Открытый вопрос: подмножества

**ФАКТ.** CSS Fontsource по подмножествам (`latin-700.css`, `cyrillic-700.css`) не содержит `unicode-range`. В браузере у каждого такого начертания диапазон `U+0-10FFFF`. Комментарий в начале `src/fonts.ts` говорит об обратном.

**ФАКТ, проверено 2026-11-11 на dev-сервере по статусам `FontFace`:**
- Chromium: `document.fonts.load` для русского «Привет мир» (Days One) и для английского «Hello world» (Ruslan Display) грузит **оба** файла, латинский и кириллический.
- WebKit: после того же вызова для русского текста оба начертания Days One остаются `unloaded`, для английского загружен только кириллический файл. Это та самая особенность WebKit, ради которой `ensureFont` с v1.4.9 грузит все начертания семейства напрямую. Значит, после `ensureFont` на обоих движках грузятся оба файла.

**Вывод.** Первое использование шрифта стоит оба подмножества. Без сети это не важно: всё лежит в кэше первого визита (D-16). Текст рисуется правильно. Неверен только комментарий в `src/fonts.ts`, северити P3. Для Ш8 цена начертания считается как сумма двух файлов, так и посчитано в §3.

## 8. Круг 3 — «Праздник» (2026-11-12)

**Вопрос.** Во втором круге направление «Праздник» закрыть было нечем. Нужна пара для дня рождения, главного повода у нашей аудитории, на 8 из 10 или выше.

**Метод.** Шесть кандидатов и два заведомо слабых контроля, вслепую и в перемешанном порядке. Контроли: два тяжёлых скрипта друг над другом; скрипт с наклоном от браузера над разреженным тонким гротеском. Всё нарисовано движком продукта в двух композициях:
- «С днём рождения / Аня · 25», где длинный акцент сжимает блок;
- «Аня / с днём рождения».

Фоны: тёмный кадр с солнцем, светлый пляж, чёрная сцена. Независимый арт-директор получил только картинки и коды (`scratchpad/pairs3`, ключ в `key.json`).

**Итог (ФАКТ по оценке, уверенность средняя: статичные кадры, без телефона).**

| Код | Пара | Балл |
|---|---|---|
| P02 | Caveat Bold, Unbounded Bold капсом | **8** — единственная держит обе композиции и оба фона |
| P05 | Unbounded Black капсом, Great Vibes | 7 (8 только в «Аня / …» и с правкой) |
| P01 | Pacifico, Oranienbaum капсом | 7 |
| P07 | Lobster, Tenor Sans капсом | 7 — «то, что уже есть в шаблонах CapCut» |
| P03 | Yeseva One, Great Vibes | 6 |
| P08 | Marck Script, Oranienbaum капсом | 5 — «С» читается как «Є» |
| P04 | контроль: Lobster над Pacifico | 4 |
| P06 | контроль: Bad Script с наклоном, Raleway в разрядку | 3 |

Контроли получили низшие баллы, поэтому оценки действительны.

**Решение.** P02 взята девятой парой «Праздник» с правкой директора: капс на 10% мельче, разрядка +0,06. Образец — «Аня / с днём рождения», разбиение `first` («С днём / рождения»). В ленте «Праздник» стоит вторым и не рядом с «Влогом», где тот же Caveat.

**Находки, которые идут дальше.**
- Тонкая или мелкая опора под длинным акцентом выходит мельче 2% высоты кадра и на телефоне не читается. Это касается P01, P03, P05, P07, P08. Вписывание сжимает весь блок, поэтому опора нуждается в нижней границе кегля. Это гипотеза для следующего шага движка, проверять на iPhone.
- Связные скрипты заводят росчерки в пробел: «С днём» читалось как «Сднём». Исправлено правилом 0,22 кегля белого между словами в тексте из нескольких шрифтов (ADR-П2).

## 9. Ш5 — слепое сопоставление с направлениями (2026-11-13)

**Метод.** Девять пар каталога перемешаны под кодами S1–S9. Все нарисованы движком на одних нейтральных словах: «Суббота / утро в городе» на тёмном кадре и «Наше лето / выпуск 7» на светлом. Так слова не подсказывают направление. Независимый арт-директор сопоставил каждую пару с девятью направлениями. Направления можно было повторять, а исключением пользоваться нельзя.

**Итог (ФАКТ по оценке, сила средняя: один судья, 9 пар).**
- Угадано 8 из 9 (89%), порог Ш5 — 80%.
- Уверенно узнаны «Нежно», «Воздух», «Джаз», «Обложка». «Подиум», «Дерзко», «Плёнка», «Влог» узнаны со средней уверенностью.
- Промах: «Праздник» принят за «Влог», второй выбор — «Дерзко». Обе пары держатся на Caveat Bold. На нейтральных словах их различает только подпись, а она слишком мелкая.

**Вывод.** Праздничность «Празднику» даёт в основном текст («С днём рождения»), а не шрифт. В следующем круге стоит попробовать праздничный акцент без Caveat. Сейчас круг 3 других пар на 8 из 10 не дал: Pacifico, Lobster и Marck Script набрали 7, 7 и 5.
